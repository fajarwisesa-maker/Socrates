# Disruption history (SYNTHETIC)

`disruptions.csv` holds **80 synthetic, invented** Indonesian logistics disruptions. They
are not real events. They are the context rows SAP RPT-1.6 learns from when
`DELAY_MODEL=rpt` (v2 step 3): SIAGA sends them with one row for the current case, whose
`delay_hours` is `[PREDICT]`.

| Column | Values |
| --- | --- |
| `id` | `H-001` … (index column; the case row is `QUERY`) |
| `cause` | flood, landslide, road_closure, port_strike, accident, festive_congestion (same names as the precedents) |
| `corridor` | Pantura, Trans-Java toll, Tanjung Priok, Merak-Bakauheni |
| `month` | 1–12 |
| `rain_level` | none, light, moderate, heavy (the case row leaves it empty: no signal reports rain) |
| `signal_sources` | number of signals |
| `official_notice` | y / n |
| `delay_hours` | the target |

Generated by `scripts/make_history.py` (fixed seed). The patterns are plausible, not
measured: wet-season (Oct–Mar) Pantura floods last 2–3 days, longer with heavy rain and an
official notice; closures and accidents cost hours; port strikes 2–5 days.
